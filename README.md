One sentence, at most 200 characters, explaining the modern internet to a
time traveler who has just stepped out of the year 1800 — built only from
things a person from 1800 already knows: a road, a post office, a library.

> Picture a single road joining every post office and library on earth, so
> your letter reaches any door at once, and any book in the world answers
> you back before you can blink.

## Run it

```sh
node main.ts
```

It writes the sentence to `/output/entry.txt` (creating `/output` if needed).
Requires Node 22.18 or later; the grader runs Node 22.23.4. The program is
deterministic: every run writes the same bytes.
